# SketchOS 系统字体

> 本文件由 `tools/mkfont.py` 自动生成（`bash scripts/fonts.sh`），请不要手工修改。

## 字体与许可证

- 来源字体：**霞鹜文楷 / 霞鹜文楷等宽**（LXGW WenKai / LXGW WenKai Mono）v1.530，作者 LXGW，基于 Fontworks 的 Klee One。手写楷体风格，和 SketchOS 的手绘界面很配。
- 下载地址：<https://github.com/lxgw/LxgwWenKai/releases/tag/v1.530>
- 许可证：**SIL Open Font License 1.1**，全文见同目录的 [`OFL.txt`](OFL.txt)（系统里安装在 `/usr/share/fonts/OFL.txt`）。OFL 允许自由使用、修改、嵌入和再分发，条件是附上版权声明和许可证、不单独出售字体。
- 这里的 `.skf` 文件是从原字体**转换格式**得到的位图字体，属于 OFL 所说的“修改版本”。原字体声明了保留字体名称（“霞鹜”“LXGW”等），所以转换后的字体不使用这些名字，统称为 **SketchOS Sans / SketchOS Mono**；“霞鹜文楷”只用来说明来源。

## 字重的选择

生成前把 Regular 和 Medium 在各个字号下渲染在“纸”色背景上对比（`python3 tools/mkfont.py --src <字体目录> --compare 对比图.png`）：

- **16px（正文、终端）选 Medium**：Regular 的笔画在 16px 下只有 1 像素左右，抗锯齿后成了浅灰色，在暖白色纸面上发虚、看久了累眼；Medium 笔画更实，小号汉字的结构也更清楚。
- **20px（标题、按钮）选 Medium**：和正文保持同一字重，按钮文字更醒目。
- **32px（大字）选 Regular**：字号大了以后 Regular 已经足够黑，还保留楷书轻盈的笔意，像铅笔写的；Medium 在这个尺寸显得像马克笔，太重。

## 生成方法

1. `scripts/fonts.sh` 从 GitHub 下载 4 个 TTF 和 OFL.txt 到 `$WORK/fonts/`（已缓存就跳过）。
2. `tools/mkfont.py` 用 Pillow（内部是 FreeType）把每个字画到灰度图上，裁成“有墨的最小矩形”，记下相对笔位的左偏移、相对基线的上偏移和前进宽度，写成 `.skf`：32 字节文件头 + 按码点排序的 16 字节索引 + 8 位覆盖率位图（格式见 `sketch/font.h`）。内容相同的位图只存一份。
3. ascent/descent 取自字体的度量（FreeType 的 size metrics）；比例字体的行高取 max(ascent+descent, 字体推荐行高)；等宽字体的行高严格等于 ascent+descent。
4. 等宽字体：格宽 = 字母 M 的前进宽度；每个字的前进宽度 = `sk_wcwidth(码点) × 格宽`（宽度表直接从 `font.c` 里读，保证和 C 代码一致）。汉字、全角字符正好两格；“东亚歧义宽度”字符（“”…—αβ●→ 等）按 Unicode 标准占一格——原字形太宽时，先换用比例字体的窄字形，还放不下就缩小：扁长的（— …）只压窄，其它的（● ★ →）等比例缩小以保持形状。
5. 制表符和方块元素在等宽字体里按像素合成：竖线画满整个行高、横线画满整个格宽，相邻格子拼起来是连续的线；圆角和斜线 8 倍超采样后缩小，带抗锯齿。
6. 覆盖率量化成 16 级（0、17、34 … 255），仍按 8 位存储、格式不变：抗锯齿边缘有 16 级灰度时肉眼看不出差别，但取值少了，gzip 压缩后字体小约 40%（网页版要通过网络下载整个系统）。

## 已知的细节

- 少数带重音的大写字母（À É Ñ Й 等）比 ascent 高 1 像素（FreeType 对度量取整造成），在终端里可能和上一行重叠 1 像素。
- 源字体没有组合附加符号（U+0300–036F），这些字符宽度为 0、不显示；Latin-1 里的预组合字母（é ñ ü …）正常显示。
- 等宽字体里歧义宽度的几何符号和箭头被缩进一个半角格子，显得比较小——这是“歧义宽度占一格”这条终端惯例的代价。

## 等宽字体的格子约定（终端用）

- 一个格子宽 `sk_font_cell_width()`、高 `sk_font_line_height()`；
- 在格子里画字时，基线 = 格子顶边 + `sk_font_ascent()`；
- 双宽字符（`sk_wcwidth()==2`）占两个格子，字形的前进宽度正好是两格。
